# YouTube-Playlist-tool
עוזר להוריד מצביעים של רשימות של YouTube ולייצא אותם ל־CSV עבור Google Sheets.

## מפתח API
האתר משתמש במפתח שבשרת: משתנה הסביבה `YOUTUBE_API_KEY` ב־Vercel (הפונקציה `api/yt.js`).
כשהמשתנה מוגדר, המבקרים לא צריכים מפתח משלהם. בלי המשתנה, או כשפותחים את `index.html` ישירות מהמחשב, מופיעה תיבה להדבקת מפתח אישי.
לעולם לא לשמור את המפתח בקוד.
